Setiap data latihan, rapor materi, atau pesan baru yang masuk ke Firebase otomatis diteruskan ke Bot Telegram Guru / Grup Orang Tua.

Menunggu Konfigurasi

Cara Cepat Setup Bot Telegram:

1. Buka Telegram, cari @BotFather → ketik /newbot → salin HTTP API Token yang diberikan.

2. Cari bot baru kamu di Telegram lalu klik Start (atau masukkan bot ke Grup kelas bila ingin notif grup).

3. Cari @userinfobot (untuk Chat ID pribadi) atau buka https://api.telegram.org/bot<TOKEN>/getUpdates setelah chat ke bot untuk melihat angka Chat ID.
